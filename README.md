# nlp-coursework

Small NLP exercises completed as part of my Data Science & AI coursework.  

The repository includes:
- Sentiment classification using TF-IDF, word/bigram features and Logistic Regression with Scikit-learn.
- Multiclass intent classification using DistilBERT and Hugging Face Transformers, including tokenization and task-specific fine-tuning.
These exercises were used to explore the difference between traditional feature-based NLP techniques and pretrained transformer models.
